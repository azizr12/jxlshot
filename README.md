## Overview

JXLShot is a lightweight, C-based utility designed to capture high-fidelity monitor screenshots on Windows utilizing the JPEG-XL (JXL) image codec. The primary objective of this project is to deliver superior image compression alongside exceptional color fidelity. This addresses the inherent quality and color degradation associated with the JPEG format, as well as the suboptimal compression ratios of the PNG format.

## Key Features

- **Advanced Compression**: Achieves an optimal balance between file size and visual integrity using the JPEG-XL codec.
- **High Dynamic Range (HDR) Support**: Captures and preserves HDR metadata for compatible displays.
- **Comprehensive Display Support**: Fully compatible with varying DPI settings, wide color gamuts, and multi-monitor configurations.
- **Configurable Compression**: Users may explicitly control lossy compression parameters or retain the default lossless configuration via the application settings.

## Installation and Usage

1. **Installation**: Execute the provided Windows Installer. Upon installation, the application will operate seamlessly in the background.
2. **Default Behavior**: Launching the application normally will open the primary Capture Tool interface.
3. **Capture Options**: The utility provides the user with the option to capture either a specific screen region or the entirety of the monitor.
4. **Export Directory**: Users may designate a custom export path. If no path is specified, screenshots are automatically saved to the default system Pictures folder.

## Keyboard Shortcuts

The application provides intuitive global keyboard shortcuts for rapid capture, which may be customized via the settings menu:

- **`Print Screen`**: Captures a full-screen screenshot of the primary monitor.
- **`Ctrl` + `Print Screen`**: Activates the region selection tool to capture a specific area of the screen.
- **System Tray Menu**: All capture functions and settings are also accessible via the application's system tray icon.

## Recommended Applications for Previewing

To ensure accurate rendering and previewing of JPEG-XL (JXL) files, particularly those containing High Dynamic Range (HDR) data, it is recommended to utilize one of the following compatible applications:

- **BandiView Pro**: Offers robust, native support for advanced image formats and high-fidelity HDR content.
- **Chromium-based Browsers**: Browsers such as Google Chrome, Brave, or Vivaldi, provided they are equipped with the latest version of Microsoft's JPEG-XL plugin.
- **Windows Photos App**: The native Microsoft Photos application, which supports JXL rendering when the appropriate system codec extensions are installed.
